# Web App with Docker and Jenkins

This project demonstrates the skills I developed while following the KodeKloud CI/CD roadmap. It brings together the key concepts and tools I learned to build and deploy a web application using Docker and Jenkins.

>[!IMPORTANT]
> **Project inspiration:** The original project idea was shared by [Vishakha Sadhwani](https://www.youtube.com/watch?v=X6Kw2_wZr1E) and created by @prashantgohel321. This is my own implementation, created as a learning project.
